# 历史行情与交易策略探索（早期研究脚本）

这份材料整理自本地 stock 目录，用于展示早期围绕股票、ETF 历史行情开展的 Python 实验，原脚本保持原样。

## 做过的探索

- `rd.py`：通过 AKShare 查询 A 股历史行情的接口调用示例。
- `stl.py`：调用 statsmodels 的 seasonal_decompose，对价格进行乘法模型的趋势、季节项和残差分解。文件名虽为 stl，实际没有使用 STL 算法。
- `chuli.py`：扫描分解周期，尝试比较季节项与残差的相对大小。
- `tryzhang.py`：比较多种开盘价、收盘价关系构成的交易规则，扫描 0.9 至 1.1 的阈值；包含整百股交易和简化卖出成本。
- `惯性.py`、`惯性 copy.py`：尝试基于历史价格变化的多标的交易，使用随机遍历顺序、持仓状态及简化交易成本。
- CSV：原始历史行情材料，主体数据截至 2023 年 2—3 月。股票和 ETF 混合

## 当时代码的问题

1. 多个脚本引用的 `516390.csv` 不在原目录中
2. 多标的脚本用负索引取信号、正索引取成交价，造成时间错位。例如 `300339.csv` 中 data=365 时，信号取自 2021-08-18，成交价却取自 2014-04-18。历史收益不可采信。
3. 多标的数据以行号而非交易日期对齐；随机数按当前时间播种，重复运行不保证一致。
4. `惯性 copy.py` 存在有些分支清空持仓却未把卖出所得计入现金的问题。
